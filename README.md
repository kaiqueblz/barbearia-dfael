# Landing Page Barbearia

Projeto em React + TypeScript + Vite.

## Rodar
```bash
npm install
npm run dev
```

## Personalizar
- WhatsApp: constante `WHATSAPP` em `src/App.tsx`
- Serviços/preços: array `servicos` em `src/App.tsx`
- Endereço/horários/Instagram: seção `contato` em `src/App.tsx`
- Imagens: `public/images/`
